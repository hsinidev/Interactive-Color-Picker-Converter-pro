## ✨ Key Features

-   🎨 **Visual Color Picker**: Native, intuitive color selection.
-   ✍️ **Direct HEX Input**: Smart input validation for Hex codes.
-   ⚡ **Instant Conversions**: Real-time calculation of RGB and HSL values.
-   📋 **Clipboard Integration**: One-click copy functionality.
-   📜 **Color History**: Tracks your recent palette usage.
-   ⚖️ **Legal Compliance**: Built-in modals for Privacy, Terms, and DMCA.
-   🔍 **SEO Powerhouse**: Contains extensive structured data (JSON-LD) and rich content.
-   🌌 **Smoky Green Theme**: A unique, animated, multi-colored background experience.

## 🛠️ Getting Started

### Prerequisites

-   [Node.js](https://nodejs.org/en/) (v16+)

### Installation

1.  **Clone the repository:**
    ```sh
    git clone https://github.com/hsinidev/color-converter.git
    ```
2.  **Install dependencies:**
    ```sh
    npm install
    ```
3.  **Run locally:**
    ```sh
    npm start
    ```
